# 基于STM32的软件PWM呼吸灯(Non-Blocking Software PWM)

## 项目简介
本项目基于 STM32F103ZET6 芯片，实现了纯软件模拟的 PWM 呼吸灯效果。
代码完全抛弃了 `HAL_Delay()` 死等延时，采用 `HAL_GetTick()` 构建了毫秒级时间片轮询架构。在实现渐亮渐暗呼吸效果的同时，保证了 CPU 的实时响应能力，不影响系统中其他外设（如串口接收）的运行。

## 开发环境
*   **主控芯片**: STM32F103ZET6 (ARM Cortex-M3)
*   **底层库**: STM32 HAL 库
*   **配置工具**: STM32CubeMX
*   **开发环境**: VS Code + Keil Assistant
*   **核心外设**: GPIO 推挽输出 (PF8 引脚，低电平点亮)

## 核心逻辑
1.  **非阻塞时间片**: 使用 `HAL_GetTick() - last_tick >= 1` 替代阻塞延时，实现 1ms 的精准调度。
2.  **软件PWM模拟**: 通过主循环内的计数器 `pwm_cnt` (0-100 循环)，结合动态修改的 `duty` (占空比)，精准控制引脚高低电平的翻转时间。
3.  **呼吸算法**: 引入 `dir` (方向) 变量。在周期结束时，控制占空比 `duty` 递增或递减，实现亮度的平滑过渡。

## 已知缺陷与迭代方向
*   **当前缺陷**: 因为是纯软件模拟，PWM 频率受限于时间片（当前周期 100ms，即 10Hz）。在占空比极低（低亮度）时，人眼视觉暂留效应减弱，能观察到轻微的频闪。
*   **优化方向**: 下一版本将弃用软件模拟，直接配置 STM32 内部的硬件定时器（TIM）输出硬件 PWM，将频率提升至 50Hz 以上，彻底消除频闪并释放 CPU 资源。

## 如何运行
1. 安装STM32CubeMX和Keil 5。
2. 克隆本仓库，使用Keil打开`MDK-ARM/PWM_Breath.uvprojx`。
3. 编译并烧录至STM32F103ZET6开发板。
4. 观察PF8引脚连接的LED，即可看到呼吸灯效果。
